# GPT Web Pro × Codex 协作协议

## 角色

- GPT Web Pro 是 Orchestrator：只负责公开竞品调研、单批规划、验收标准和复审。
- Codex 是 Executor：只负责本地仓库检查、代码修改、测试、截图和证据回传。
- Pro 不直接修改仓库；Codex 不自行扩大 Pro 选定的页面或能力范围。
- Codex 保留技术否决权：不存在的路径或接口、违反仓库约束的方案、无法真实测试的状态、要求新增平行实现的方案，必须退回 Pro 修订，不能用本地猜测补齐。

## 仓库事实门禁

每个新批次开始前，由 Codex 生成或更新 `docs/ORCHESTRATOR_REPO_MANIFEST.md`。Pro 必须先以该清单为准：

- 仓库根目录与当前分支；
- 已存在的路由、组件、API、DTO、状态和测试锚点；
- 当前已完成能力和不可回退边界；
- 允许修改文件与禁止范围；
- 可真实运行的测试、构建和浏览器验收命令。

Pro 对清单之外的信息不得当作事实。需要额外文件时，只能列出“待 Codex 核验的假设”；Codex 核验后才能进入执行包。

## 每轮输入

Pro 先阅读脱敏上下文包，并遵守：

1. `AGENTS.md`
2. `docs/CURRENT_PRODUCT_PRIORITY.md`
3. `docs/EXISTING_CAPABILITY_MAP.md`
4. `docs/MODEL_DELEGATION_POLICY.md`

响应编制已按 Loopio List View 收敛；合规审阅已按 GovDash Compliance Matrix / Review Mode 与 Responsive Source View 对齐。下一轮从尚未对齐的核心流程中只选择一个独立可验收切片。

## Pro 的执行包

Pro 应先使用官方公开来源完成调研，再生成一个可下载 ZIP。ZIP 至少包含：

- `EXECUTION_BRIEF.md`：单一竞品、单一用户任务、允许修改文件、禁止范围、复用决定与交互清单。
- `REFERENCE_MAP.md`：官方 URL、截图或页面区域，以及每个参考点对应的本地可见元素。
- `ACCEPTANCE.md`：P0/P1/P2 标准、同视口截图要求、响应式要求、测试命令和明确的 `ACCEPT` 条件。

执行包不得包含产品代码，不得要求创建平行路由、API、DTO、状态模型或第二套工作台，除非先证明现有锚点无法扩展。每轮只处理一页或一个紧密能力。

Codex 收到执行包后先做技术可行性审包，再开始实现。审包至少核对路径存在、接口签名、状态归属、测试命令和允许范围；不通过时要求 Pro 发布修订版，不直接执行。

## 复审循环

Codex 完成实现后向同一 Pro 会话回传：

- 变更文件与复用锚点；
- 测试、lint、类型检查和构建结果；
- 同视口桌面与移动截图；
- 与 `ACCEPTANCE.md` 的逐项对照；
- 已知限制或未实现项。

Pro 只在产品任务、UI、设计、交互和 Agent 边界的 P0/P1 条件通过时回复 `PRODUCT_ACCEPT`；否则给出下一轮具体修正项。Codex 只在路径、接口、架构和测试通过时给出 `TECH_ACCEPT`。只有两者同时出现，本批才最终关闭。最多六轮，不把新页面或新能力插入当前循环。

安全、权限、浏览器策略、部署和一般性限制不作为产品评审主题，不进入页面卖点或占用复审篇幅；只在实际操作需要时作为后台底线处理。

## 本地制品桥接

- Pro 的 ZIP 只作为交换格式，不作为执行环境。
- Codex 从浏览器下载目录定位文件，先列出内容并核对文件名、版本和范围，再读取或转存到本地检查点。
- ZIP 下载不可用时，Pro 直接在回复中输出 `EXECUTION_BRIEF.md`、`REFERENCE_MAP.md` 和 `ACCEPTANCE.md`；Codex 在本地重新封装，流程继续。
- Pro 不生成或传递可执行脚本、依赖包、凭据或产品代码。

## 中断恢复

- 浏览器会话不是唯一状态源。每轮执行包、Executor 证据包、轮次、会话 URL、Pro 结论和 Codex 结论都写入本地检查点。
- 浏览器安全策略、登录过期或下载中断时，Codex 停在最后一个已落地检查点；恢复同一会话，或把事实清单和检查点上传到新会话继续。
- 不通过复制浏览器 Cookie、密码、令牌或其他敏感信息来恢复会话。

## 数据边界

- 上下文包只含源码、测试、公开竞品资料、合成截图和产品文档。
- 不包含 `.env`、凭据、数据库、真实客户资料、用户上传物、依赖目录或构建产物。
- 不向竞品产品上传任何本地项目文件。
