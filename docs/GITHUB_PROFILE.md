## About

推荐 description：

> BidEvidence: a traceable bidding workflow connecting requirements, evidence, responses, and human review.

如果使用中文：

> 标证通 BidEvidence：连接招标要求、企业证据、响应编制与人工复核的可追溯投标工作流。

## Topics

建议设置：

- `typescript`
- `react`
- `nextjs`
- `fastapi`
- `workflow`
- `rfp`
- `document-processing`
- `human-in-the-loop`

不建议把 `agi`、`autonomous-agent` 或 `ai-agent` 放在首批 topics。它们会让仓库第一印象偏离正式投标工作流。

- 默认分支指向最终验收版本，而不是过期执行分支。
- 根目录 README 可以完整渲染。
- 主图、docs 链接和 License 可访问。
- 不包含 `.env`、数据库、上传物、依赖目录或构建缓存。
- About description、topics 和 social preview 与 README 使用同一定位。

本文件只记录建议，不修改远程分支或 GitHub 设置。
