# UI “AI 味”复检与竞品元素映射（2026-07-19）

## 结论

当前 UI 的主要问题不是配色，而是典型生成式后台模板结构：四等分 KPI 卡片、所有状态都使用彩色药丸、均匀卡片化、过度圆角和留白，以及页面在“展示能力”而非“支持日常审阅”。本轮已在 OpenDesign 原型中移除项目目录 KPI 卡片，并改为 Saved Views、紧凑筛选、纯表格工作区和圆点状态。

## 对标与复用边界

| 来源 | 许可/属性 | 复用元素 | 不复用内容 |
| --- | --- | --- | --- |
| GovDash Proposals | 商业竞品 | 页面层级、紧凑工具栏、表格密度 | 四等分 KPI 卡片、英文产品信息架构 |
| GovDash Compliance | 商业竞品 | 章节树、逐项要求、页码与证据列 | 原产品品牌、业务命名和数据 |
| Paperless-ngx | GPL-3.0 | Saved Views、过滤器、批量动作、纯表格主界面 | 绿色品牌色和文档管理领域术语 |
| Plane | AGPL-3.0 | 项目内横向导航、紧凑行、视图切换、折叠导航 | 项目管理领域模型和 AI 助手入口 |
| OpenContracts | Apache-2.0 | 文档+标注双栏、来源跳转、人工复核模式 | 法务标注标签和聊天层 |

## 已落地修改

- 项目目录删除四个对称 KPI 卡片，替换为“全部项目 / 7 天内截止 / 高风险 / 我负责的”视图标签。
- 表格行高由 62px 收紧到 54px，状态由彩色药丸改为圆点+文本。
- 证据完备度改为百分比和已匹配数量，不再使用装饰性进度条。
- 左栏从 224px 收窄至 208px，顶部栏从 64px 收窄至 56px。
- 合规页主动作从“解析最新文件 + sparkle”改为“更新解析”，弱化 AI 营销感。
- 增加列表/表格视图切换状态、Saved Views 过滤交互、人工复核保存反馈。
- 建立竞品参考 HTML，包含原始截图、按钮、标签、过滤器、要求行、复核控件和动效关键帧，并导入 Figma。

## 复检结果

### 通过

- 视觉层级更像高频企业工作台，不再像营销 Dashboard。
- 项目目录与 Paperless/Plane 的信息密度接近，保留标证通自己的证据完备度和风险字段。
- 合规页保持“章节—要求—证据—原文”的核心路径，未退化成聊天界面。
- Saved Views、项目跳转、结论选择和保存 Toast 已进行浏览器交互验证。

### 下一轮仍需处理

- 将参考墙中的按钮、标签、筛选器和行项目整理为正式前端组件，而不是继续新增一次性样式。
- 项目表格补充批量选择后的动作栏与列偏好持久化。
- 合规页补充拖拽分栏宽度、来源跳转和 PDF 页码同步。
- Figma 的 HTML 捕获保留为布局基准；正式组件库需要绑定设计变量和组件实例。
