# BidEvidence 求职作品包文件清单

## 建议阅读顺序

1. `01-README.md`：一句话定位、七步旅程、三分钟演示与完整仓库入口。
2. `02-CASE_STUDY.md`：问题、竞品研究边界、关键产品决策、失败案例和局限。
3. `04-SCREENSHOTS/`：八张 production 产品证据、两张 README 预览、一张英文默认界面验收图、一张架构 Social Preview 与两张真实响应版本比较图。
4. `03-ARCHITECTURE.md`：前后端、规则、AI 与人工门禁的架构说明。
5. `05-TEST_EVIDENCE.md`：自动化与当前终验事实。
6. `06-RUNNING_GUIDE.md`：评审者本地运行和七步访问顺序。
7. `07-FINAL_ACCEPTANCE.md`：Pro `PRODUCT_ACCEPT`、Codex `TECH_ACCEPT`、展示验收、`RESPONSE_VERSION_ACCEPT` 与 `RELEASE_BASELINE_ACCEPT`。
8. `11-AUTHORSHIP.md`：个人主导范围、AI 协作边界和可对外表述。
9. `12-GITHUB_PROFILE.md`：About、topics、social preview 与默认分支发布清单。
10. `13-BILINGUAL_UI_ACCEPTANCE.md`：英文默认、中英切换、持久化与中文业务原文保护的验收记录。
11. `14-RESPONSE_VERSION_HISTORY.md`：不可变版本历史的竞品依据、契约、复用决定和验收结果。
12. `15-RELEASE_BASELINE.md`：`v0.1.2` 的精确范围、测试门禁、发布资产和回退基线。
