# 标证通品牌素材

本目录以用户确认的 `dart` 图标与字标为唯一母版，所有文件均为透明背景。

## SVG

- `bidevidence-icon.svg`：标准双色图标，浅色界面优先使用。
- `bidevidence-logo.svg`：标准双色横向字标，浅色界面优先使用。
- `bidevidence-icon-mono.svg` / `bidevidence-logo-mono.svg`：深色单色版本，用于打印、盖章预览和低色彩场景。
- `bidevidence-icon-inverse.svg` / `bidevidence-logo-inverse.svg`：反白版本，用于深色背景。

## PNG 与系统图标

- 根目录 `bidevidence-icon.png`：512 × 512 透明 PNG。
- 根目录 `bidevidence-logo.png`：800 × 320 透明 PNG。
- `raster/`：32、64、128、180、256、512px 图标，以及 400、800px 横向字标。
- `/favicon.ico`：32px 与 64px 多尺寸浏览器图标。

## 色彩与使用

- 品牌墨色：`#22262E`
- 品牌蓝：`#536DFE`
- 深色背景辅助蓝：`#8FA1FF`

图标和字标必须保持原始比例；不要拉伸、添加白底、阴影、渐变或单独移动蓝色箭头。四周至少保留一个蓝色箭头高度的安全留白。
