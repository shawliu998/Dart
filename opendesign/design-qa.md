# OpenDesign 视觉 QA

日期：2026-07-19
范围：项目目录、合规审阅核心工作台

## 参考与取舍

- GovDash：左侧导航密度、顶部工具条、项目列表、合规矩阵、原文联动。
- 标证通现有产品：项目阶段、风险、证据完备度、人工复核、责任人和审计边界。
- PokieQuant OpenDesign：4px 网格、语义 token、低圆角、紧凑控件、状态点与文本、隔离原型工作流。

## 已实现

- 224px 业务侧栏和 64px 顶部栏。
- 项目页：单一主操作、四项紧凑指标、过滤工具条、密集型项目表格。
- 合规页：要求列表、要求详情、招标文件原文三栏联动。
- 项目与要求搜索、项目进入、要求切换、复核状态切换、保存反馈。
- 统一 6–8px 圆角，移除大面积渐变、装饰性卡片和胶囊墙。

- [x] 1440×900 项目目录，无裁切、列宽稳定。
- [x] 1440×900 合规审阅，三栏均保留核心字段。

先迁移设计 token 与项目页表格，再迁移合规页三栏骨架；保留现有 React 业务状态和 API，不复制静态原型的数据层。
