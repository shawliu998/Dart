# 标证通 OpenDesign 核心工作台

状态：隔离设计原型，尚未合并进 `frontend/`。

## 目标

- 保留标证通的项目、要求、证据、复核与交付信息架构。
- 借鉴 GovDash 的紧凑桌面导航、过滤工具条、表格层级和“要求—证据—原文”联动。
- 使用语义 token 与可运行 HTML，让设计可审阅、可截图、可逐步迁移，而不是只保留静态效果图。

## 运行

```bash
cd opendesign
python3 -m http.server 3220
```

打开 `http://localhost:3220/`。点击第一行项目进入合规审阅，项目搜索、要求搜索、要求切换、复核结论选择和保存反馈均可操作。

## 边界

- 本原型使用确定性示例数据，不执行真实业务写入。
- 原型不改变生产页面和后端规则。
- 通过视觉审阅后，再按组件粒度迁移到 `frontend/`。
